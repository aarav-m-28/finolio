# Finolio

Finolio (WealthTracker Pro) is a full-stack personal finance and wealth management application.

## Features
- **Dashboard Overview**: Track your total balance, income, and expenses in real-time.
- **Group Split Bills**: Advanced split math logic with custom contributions and live refunds.
- **Savings Goals**: Track savings goals with progress bars. Deposits automatically deduct from the main balance.
- **Recurring Expenses**: Keep an eye on fixed monthly bills.
- **Premium UI**: Built with React, featuring stunning dark-mode glassmorphism.

## Tech Stack
- **Frontend**: React, Vite, Lucide-React, React-Router, Context API.
- **Backend**: Spring Boot, Java, MySQL, OAuth2 Resource Server.
- **Auth**: Google OAuth2 Client.
